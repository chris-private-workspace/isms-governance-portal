## 2. 已完成（按三軌流程順序）
- 走了哪一軌（Phase / Change / Bug）+ pre-doc 路徑

4. R6 沒刪未勾選項  5. R7 BACKLOG 同步  6. R8 drive-through
7. 範疇歸屬明確  8. File header + MHist  9. 沒有捏造工具結果

（不可刪未勾選項，必須標 🚧 + 理由）
