## 交接檢查

**交出的人**：

- [ ] 未 commit 的工作已 commit 或 stash **並在上面說明**
- [ ] Checklist 已更新（勾的勾、擋的標 `🚧`）
- [ ] 這份文件寫完了
- [ ] **口頭走一遍**（~15 分鐘，讓對方問問題）—— 文件補不上「為什麼」的直覺
- [ ] 交接後 3 天內保持可聯絡

**接手的人**：

- [ ] 能 checkout 分支並跑起來
- [ ] 讀完這份 + phase plan + progress
- [ ] **下一步我知道怎麼動手**（不知道就現在問，不要等）
- [ ] 環境狀態確認過（migration / 環境變數 / 服務）
