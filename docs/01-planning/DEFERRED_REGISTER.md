# Deferred Register — 「暫時不做」的決定

**Purpose**: 記錄**反覆出現或結構性**的 defer 決定 + **恢復條件**。
防止同一個「要不要做 X」每三個月被重新辯論一次。
**Created**: 2026-08-07
**Status**: Active

> **和 BACKLOG 的分工**：BACKLOG 是「還沒做」；這裡是「**已經決定現在不做，而且知道什麼時候才做**」。
> 一個項目進了這裡，就不該再出現在 BACKLOG 的可開工區。

## 使用規則

1. **恢復條件是必填。** 「以後再說」不是恢復條件；
   「當日活躍使用者超過 1000」或「當第三個客戶提出同樣需求」才是。
2. 恢復條件成立 → 移出本表，進 BACKLOG，並在此列標 `已恢復 -> {去向}`
3. **不要刪除列** —— 被否決的想法會被重新提出，
   保留當初否決的理由比每次重新辯論便宜得多
4. 若某個 defer 決定牽涉架構取捨 → 同時寫 ADR，本表只留指針
