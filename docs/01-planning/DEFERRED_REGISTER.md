## 使用規則

1. **恢復條件是必填。** 「以後再說」不是恢復條件；
   「當日活躍使用者超過 1000」或「當第三個客戶提出同樣需求」才是。
2. 恢復條件成立 → 移出本表，進 BACKLOG，並在此列標 `已恢復 -> {去向}`
3. **不要刪除列** —— 被否決的想法會被重新提出，
   保留當初否決的理由比每次重新辯論便宜得多
4. 若某個 defer 決定牽涉架構取捨 → 同時寫 ADR，本表只留指針
