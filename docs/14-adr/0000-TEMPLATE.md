# ADR-NNN: <決策標題（用結果陳述，不是問句）>

> **用於**：會約束未來的決策記錄。位置 `docs/14-adr/ADR-NNN-<slug>.md`
> 編號單調遞增 —— 先查：`ls docs/14-adr/ | sort -V | tail -1`
>
> **ADR 是輕量的 —— 目標 1 頁。** 寫成教科書就沒人寫、沒人讀。
>
> **什麼時候寫 ADR vs design note**：
> - **ADR** = 一個**決策**（選 A 不選 B），會約束未來。可以在沒有實作的情況下寫
> - **Design note** = 一次 **spike 的知識抽取**，含已驗證的不變式 + `file:line`。**必須有實作**
> - Spike 過程中做的決策 → 寫在 design note 的 §Decision Matrix，**不用另開 ADR**
>
